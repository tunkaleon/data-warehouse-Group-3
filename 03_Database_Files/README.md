# Database setup - University Library Analytics DW (SQLite)

The warehouse is **one SQLite file**: `library_dw.db`. SQLite is built into Python, so there is no server to install.
To look inside, install the free **DB Browser for SQLite** (sqlitebrowser.org).

## Scripts (run in this order)

| # | Script | Creates |
|---|---|---|
| 1 | `01_create_database.sql` | settings (foreign keys ON) and a clean reset |
| 2 | `02_create_staging_tables.sql` | 5 staging tables (raw text), 3 mapping tables (cleansing rules), ETL batch log and error log |
| 3 | `03_create_dimension_tables.sql` | 9 dimensions + seed rows (dates 2023-2027 made by a recursive query, departments, rooms, time slots ...) |
| 4 | `04_create_fact_tables.sql` | 3 fact tables with foreign keys, CHECK and UNIQUE constraints + the OLAP view `v_usage_cube` |
| 5 | `05_create_indexes.sql` | indexes for the joins and business questions |
| 6 | `06_security_rbac.sql` | roles, permission matrix, users table, masking view, department views |
| 7 | `07_audit_logging.sql` | audit table, triggers, audit report view |
| - | `sample_data.sql` | all data (staging + warehouse), **generated by the ETL** |

## Option A - one command (recommended)

```bash
python build_database.py               # scripts 01-07 -> empty warehouse (then run the ETL)
python build_database.py --with-data   # scripts 01-07 + sample_data.sql -> loaded warehouse
```

## Option B - DB Browser for SQLite

1. *New Database* → save as `library_dw.db` in this folder.
2. Tab **Execute SQL** → open `01_create_database.sql` → **Execute all (F5)**.
3. Repeat for scripts 02 to 07, then `sample_data.sql`.
4. **Write Changes** (Ctrl+S).

## Option C - sqlite3 command line

```bash
sqlite3 library_dw.db < 01_create_database.sql
sqlite3 library_dw.db < 02_create_staging_tables.sql
...                                         # 03 to 07
sqlite3 library_dw.db < sample_data.sql
```

## Check that it worked

```sql
SELECT COUNT(*) FROM dim_date;          -- 1827 (5 years + 1 'not returned' row)
SELECT COUNT(*) FROM fact_book_loan;    -- 2205
SELECT COUNT(*) FROM fact_digital_usage;-- 4023
SELECT COUNT(*) FROM fact_room_booking; -- 2837
PRAGMA foreign_key_check;               -- no rows = no problems
```

## Notes

* SQLite checks foreign keys only when `PRAGMA foreign_keys = ON` is set on the connection (the scripts and Python programs do this).
* Queries with `SQRT()` (Q11) need SQLite 3.35+; `run_business_queries.py` adds SQRT itself if needed.
* Users and passwords are created by `07_Security_Documentation/security_tools/secure_access.py --setup` (hashes cannot be made in plain SQL).
